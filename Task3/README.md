## Классификация данных и инструменты защиты

| Данные                                                                             | В чём необходимость защиты                                                                                  | Инструменты защиты                                                                                                    |
|------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Идентификационные данные пациентов (ФИО, дата рождения, номер телефона, email)** | Требования ФЗ-152 "О персональных данных", высокий риск идентификации при утечке, возможность мошенничества | Шифрование AES-256 в базе данных, токенизация через HashiCorp Vault, маскирование в интерфейсах, TLS 1.3 для передачи |
| **Медицинские записи (диагнозы, анамнез, результаты обследований)**                | Врачебная тайна, репутационные риски, требования к конфиденциальности медицинских данных                    | Шифрование на уровне приложения, разделение PHI от PII, доверенные среды исполнения (TEE), RBAC с атрибутами врача    |
| **Результаты лабораторных анализов**                                               | Особо чувствительные медицинские данные, связь с конкретными заболеваниями                                  | End-to-end шифрование при интеграции с лабораторией, обезличивание при передаче, PostgreSQL TDE                       |
| **Платежные данные (суммы, реквизиты, номера договоров)**                          | Финансовые риски, требования по защите платежной информации                                                 | Токенизация платежных данных, шифрование при хранении, защищенные каналы API Gateway, аудит транзакций                |
| **Адресные данные (место жительства, работы)**                                     | Дополнительная идентификация, риски физической безопасности пациентов                                       | Шифрование полей адресов, ограничение доступа по ролям, маскирование в отчетах                                        |
| **Расписание приемов и медицинские назначения**                                    | Косвенное раскрытие состояния здоровья, планирование атак                                                   | Шифрование временных меток, ограничение видимости по ролям, логирование доступа                                       |
| **Учетные данные сотрудников (логины, роли, права доступа)**                       | Риск эскалации привилегий, несанкционированный доступ к системе                                             | Хеширование паролей (bcrypt), двухфакторная аутентификация, централизованное управление через Keycloak                |
